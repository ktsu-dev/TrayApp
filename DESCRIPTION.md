The reusable skeleton behind cross-platform .NET tray tools. A tool supplies a menu model and its own platform layer; ktsu.TrayApp owns the Avalonia tray host for Windows, macOS and Linux, the tray-versus-console decision with a fallback that never kills the process, Ctrl+C and SIGTERM handling, the --for duration timer, the standard command line flags, the --status report, and debounced preference persistence over any ktsu.Essentials IPersistenceProvider. Ships MSBuild props that trim the ~190 MB of per-RID SkiaSharp natives and debug symbols Avalonia drags into a RID-agnostic dotnet tool package down to about 50 MB.
